# SITE_LAYOUT

本文件只记录本次会话中已经出现、且后续不能仅靠源码可靠还原的现场信息。未被现场或串口明确证实的内容标记为“待确认”。

## 现场坐标系

- 坐标原点：中心橙色圆 / 现场板面中心。
- 平面单位：cm。
- 方向：`+x` 向右，`+y` 向上。
- 视觉坐标：MaixCAM 输出的 LASER/CIRCLE/HOME/TILT 与上述板面坐标同向，实际精度依赖视觉识别。
- `soft=(x,y)`：控制器内部认为的平面坐标，不等于激光真实落点。
- `err=(x,y)`：串口中按 `LASER - CIRCLE` 计算的视觉误差，单位 cm。

## 通信和供电

- MCU：STM32F103 高密度器件，设备 ID 曾显示 `0x414`，Revision `Rev X`，NVM `256 KB`，Cortex-M3。
- 调试器：ST-LINK，曾显示版本 `V2J48S7`。
- 编程工具：STM32CubeProgrammer `2.22.0` / STM32CubeCLT `1.21.0`。
- 编程时板电压：`3.24 V`。
- PC 调试串口：USART1，PA9/PA10，`115200 8N1`。
- 视觉串口：USART2，PA2 TX -> CAM_RX，PA3 RX <- CAM_TX，`115200 8N1`，DMA + IDLE 接收。
- 电机总线：USART3，PB10/PB11，`115200 8N1`，RS485/Modbus-RTU，驱动型号在代码注释中为 `ZDT X42S`。

待确认：电机供电电压/电流、RS485 转换芯片型号、总线拓扑、终端电阻、屏蔽接地、MaixCAM 具体型号和固件版本。

## 现场已观察到的机械现象

- 四角巡检可以基本按路径完成，但四个圆心命中仍有偏差。
- 靠近角点时绳张力不均，部分相邻或对角线明显松紧不同。
- 用户现场明确观察：去 M3 对应角点，也就是右下/RB 方向时，M4 这根对角线会偏松；M1、M2、M3 相对更紧。
- 早期靠近某些角点时，松线严重到有一次线直接垮下来。
- 中心回零即使电机编码器回到零，激光视觉中心仍可能偏移，说明绳松弛、摩擦或绕线状态会造成不可逆的几何误差。
- 视觉有过长时间不更新的情况：LASER/CIRCLE/TILT 计数卡住，age 增长到数十秒，随后又恢复。
- 串口通信有 TIMEOUT、REJECTED、CRC_BAD；历史曾在 LB-IN2 因 M3 缓冲命令 CRC_BAD 中止。
- 最新 V13 现场串口在 RT `step=11/28 seg=2/6` 发生 M4 `0x10` 缓冲写 `TIMEOUT`，`trigger_attempted=0`，失败前仍看到中心圆 `circle=(0.00,0.00)`；用户现场判断可能与 RT 附近线过紧/负载有关，且单纯等待后原路径重试不足以改变松紧状态。
